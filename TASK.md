## Техническое задание (ТЗ)
**IDE:** Visual Studio Code  
**Название плагина:** DotSync  
**Назначение:** Структурная синхронизация конфигурации переменных окружения из файла `.env` в файл `.env.example`.

### Основные требования:
* **Чтение файла `.env`** в корневой директории открытого рабочего пространства (workspace).
* **Чтение файла `.env.example`**. При его отсутствии — инициализация в памяти как пустого.
* **Структурная синхронизация**: плагин должен генерировать файл `.env.example`, полностью повторяющий порядок следования элементов файла `.env`.
* **Перенос структуры и комментариев**: пустые строки переносятся без изменений. Разрешенные комментарии (начинающиеся с `#!`) экспортируются. Секретные комментарии (начинающиеся с `#`) игнорируются.
* **Защита конфиденциальности**: значения ключей из `.env` отбрасываются.
* **Сохранение дефолтных значений**: если ключ уже существует в текущем `.env.example` (например, имеет заданное пользователем безопасное значение), при генерации нового файла эта строка должна быть сохранена полностью.
* **Уведомление пользователя** о результатах работы (ошибки, информация о создании файла, успешная синхронизация, отсутствие изменений) через стандартный UI VS Code.
* **Механизм вызова**: ручной запуск через Command Palette (команда `dotsync.sync`).
